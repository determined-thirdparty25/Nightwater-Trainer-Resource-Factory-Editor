## 💡 Tips for Best Experience

- **Always back up your game save before making large changes.** Use the Config Manager's export feature for easy restoration.
- **Start with small adjustments.** For example, increase production speed by 2x before trying 10x to ensure your system handles it smoothly.
- **Use automation profiles as "presets."** Create one profile for resource gathering, another for combat scenarios, and switch based on what you're doing in-game.
- **Keep the application open while you play.** Changes apply in real time, but the game must be running for some settings to take effect.
- **If the game crashes,** reload your save and reapply your changes. This usually happens if you edit values while the game is writing its own save data.

## 🆘 Troubleshooting

**"The application does not start."**

- Right-click the file and select "Properties."
- In the "Compatibility" tab, check "Run this program as an administrator."
- Try again.

**"Changes don't show up in the game."**

- Close the application, open Nightwater, and load your save fresh.
- Then switch back to the editor, make changes, and save them.
- Reload the save in-game.

**"The window appears tiny or blurry."**

- This happens if your Windows display scaling is above 100%.
- Right-click the executable, go to Properties > Compatibility > Change high DPI settings.
- Check "Override high DPI scaling behavior" and set it to "Application."
